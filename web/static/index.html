    关于这个工具

    一个夏汉混排的整行识别模型：西夏文（Unicode 全部 5,878 个规范字）、约 8,400 个汉字、标点、拟音字母放在同一个字表里一次读出，不需要先分字种。

    以上是在测试书页上的成绩。

    • 只识别横排行；竖排文字会被标出来，暂不识别。
    • 没有语言模型校正：一个字读错不会被上下文纠正，所以看到错字请顺手改掉。
    • 你的校对先进入待审核队列，审核通过后才会用于训练。

    模型和训练代码在 GitHub：FlagRain/tangut-mixocr

    行检测：PaddleOCR PP-OCRv6（Apache-2.0）。西夏字体：Noto Serif Tangut（SIL OFL 1.1）。
